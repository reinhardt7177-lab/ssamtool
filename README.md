# 쌤툴

학교 잡업무를 브라우저 안에서 끝내는 도구함이에요. 넣은 파일과 명단은 서버로 올라가지 않고, 각자의 브라우저 안에서만 처리돼요.

## 들어 있는 도구

| 영역 | 도구 |
|---|---|
| 문서·파일 | 문서 사진 용량 줄이기 (HWPX·DOCX·XLSX·PPTX), PDF 합치기·붙임 문구 |
| 라벨·이름표 | 라벨지·이름표 메이커 |
| 공문서·행정 | 공문 작성 규칙 검사 |
| 계획서·보고서 | 안전교육 시수표 |
| 재정·물품 | 품의 준비 도우미 |
| 나이스·학적 서류 | 교외체험학습 서류 |
| 학부모 소통 | 가정통신문 메이커, 회신서 취합, 상담주간 배정표 |

## 개발

```bash
npm install
npm run dev
```

`main` 브랜치에 올리면 GitHub Actions가 빌드해서 GitHub Pages로 배포해요.
